# Java fájlbaírás beadandó


## Java fájlok:

#### App.java:
* belépési pont
* egy tesztüzenettel meghívja a fájlba író metódust
#### Writable.java:
* interfész, amely előírja a fájlba író metódus megvalósítását
#### Writer.java:
* implementálja a Writable interfészt
* felülírja és megvalósítja a fájlba író metódust
